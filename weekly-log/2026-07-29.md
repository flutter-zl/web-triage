- **Labels to remove**: none
- **Title cleanup**: none
- **Comment**: none
- **Reasoning**: This is deterministic heap corruption and an indefinite CPU spin in the multi-threaded Skwasm renderer, with a production workload and a runnable reproduction.
- **PR review**: [#190048](https://github.com/flutter/flutter/pull/190048) addresses the root cause by linking pthread-enabled system libraries so Skia synchronization is real instead of stubbed while workers share memory.
