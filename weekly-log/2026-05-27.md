### #186751 - Flutter driver error logger assumes `stderr` which breaks web
- **Action**: triage
- **Priority**: P3
- **Suggested assignee**: mdebbar
- **Labels to add**: triaged-web, P3, has reproducible steps
- **Labels to remove**: (none)
- **Reasoning**: Clear bug filed by jakemac53 (dart-lang) with a stack trace pointing at the exact line. Affects `flutter_driver` integration tests on web/DDC. Low impact (workaround: tests still run; just noisy error), so P3.
- **Root cause**: `_defaultDriverLogger` in `packages/flutter_driver/lib/src/common/error.dart:58` unconditionally calls `stderr.writeln`, which throws `UnsupportedError` on DDC because `dart:io`'s `StdIOUtils._getStdioOutputStream` isn't implemented in the browser. Fix is to catch `UnsupportedError` and fall back to `print`/`console.error` when running on web.

### #186472 - [Google3 Bug][A11y]: Slider reads "50, Slider" on initial focus with screenreader
- **Action**: triage
- **Priority**: P1
- **Suggested assignee**: flutter-zl
- **Labels to add**: triaged-web, P1, engine, browser: safari, c: regression
- **Labels to remove**: (none)
- **Reasoning**: Confirmed reproducible by chunhtai who passed it to the web team noting it's an internal P1 (`customer: google`) blocking a client launch within a quarter. All sliders are broken on web when semantics is enabled via the "enable accessibility" button — voiceover reads the placeholder/default "50" instead of the real value. Goes to flutter-zl per the a11y routing.
- **Root cause**: The engine's slider semantics handler renders an `<input type="range">` but only writes ARIA attributes; the input's `value` attribute itself never gets set. The bug surfaces only when semantics is enabled lazily via the `enableAccessibility` flow (e.g. VoiceOver's first focus on the placeholder button), not when `ensureSemantics()` is called eagerly at startup. Likely missing a `value` write in the slider role builder's update path when transitioning from the placeholder semantics tree to the live one. Look at `lib/web_ui/lib/src/engine/semantics/slider.dart`.
